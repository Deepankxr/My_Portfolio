Problem

A financial-services workflow required people to read unstructured documents and assemble loan application details by hand. Finding and re-entering the relevant information slowed preparation.

What I built

I built an agent that reads financial documents, retrieves relevant context with Pinecone and uses Gemini and OpenAI to interpret and structure the information. Supabase supports the application data. The output is a prepared loan application.

Outcome

The system automated document interpretation and application preparation within the described workflow. Processing-time reduction, accuracy and financial outcomes are unmeasured here.
